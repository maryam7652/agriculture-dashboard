# Global Agriculture Data Terminal

## 📊 Project Overview
This project is a professional-grade, interactive data visualization dashboard analyzing international agricultural outputs, livestock yields, and harvested areas using FAOSTAT data. The application features a sleek, monochrome executive terminal interface, providing macroeconomic insights through 13 dynamic, interconnected charts.
